🌤️ Weather App with Future Forecast
A simple web application that provides current weather information and future forecasts. Built for practice with API integration and weather data handling.

📌 Overview
The Weather App with Future Forecast allows users to:

Check current weather details (temperature, humidity, wind speed)

View weather forecasts for the next few days

Search weather data by city name

This app is built using a weather API and was created as part of a learning project to practice working with real-time data.

🛠️ Tech Stack
HTML, CSS, JavaScript

OpenWeatherMap API
